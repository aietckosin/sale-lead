# ระบบอ่านบิลอัตโนมัติ (Bill Reader) — คู่มือติดตั้ง

ผู้แทนถ่ายรูปบิลแล้วส่งผ่าน Google Form จากนั้นระบบจะทำงานเองทั้งหมด ไม่ต้องเปิด Claude หรือแชตใด ๆ

1. อ่านบิลด้วย Gemini (เลขที่บิล, วันที่, ลูกค้า, โรงพยาบาล, รายการสินค้า, ยอดรวม)
2. เปลี่ยนชื่อไฟล์เป็น `BILL_<เลขที่บิล>_<โรงพยาบาล/ลูกค้า>.jpg` แล้วย้ายไปโฟลเดอร์บิล แยกตามเดือน (`2026-11`)
3. เพิ่มแถวในชีต **Bills** (1 แถวต่อ 1 บิล) และชีต **Bill items** (1 แถวต่อ 1 รายการสินค้า)
4. แถวที่ต้องตรวจจะมีสถานะเป็น **CHECK** (สีเหลือง) หรือ **ERROR** (สีแดง) พร้อมเหตุผลในคอลัมน์ Check notes เช่น เลขที่บิลซ้ำ, อ่านช่องไหนไม่ได้, ยอดรายการไม่ตรงยอดรวม

ดาวน์โหลดเป็น Excel ได้ทุกเมื่อ: **ไฟล์ > ดาวน์โหลด > Microsoft Excel (.xlsx)**

ใช้เวลาติดตั้งครั้งเดียวประมาณ 30 นาที

---

## สิ่งที่ต้องมี

- บัญชี Google (แนะนำบัญชีบริษัท เพราะไฟล์และชีตจะอยู่ในบัญชีนี้)
- Gemini API key ฟรีจาก Google AI Studio

> **เรื่องข้อมูลลูกค้า:** ถ้าใช้ Gemini แบบฟรี Google อาจนำข้อมูลที่ส่งไปใช้ปรับปรุงบริการ ถ้าบิลมีข้อมูลที่ไม่ควรออกนอกบริษัท ให้เปิด Billing ในโปรเจกต์ของ API key (แบบเสียเงิน Google จะไม่นำข้อมูลไปใช้) ค่าใช้จ่ายปกติแค่ไม่กี่บาทต่อร้อยบิล

---

## ขั้นที่ 1 — ขอ Gemini API key (5 นาที)

1. เปิด https://aistudio.google.com แล้วล็อกอิน
2. กด **Get API key** > **Create API key**
3. คัดลอก key ไว้ (ขึ้นต้นด้วย `AIza...`) **ห้ามส่ง key นี้ในแชตหรือใส่ในโค้ด**

## ขั้นที่ 2 — สร้าง Google Form (10 นาที)

1. เปิด https://forms.google.com > สร้างฟอร์มเปล่า ตั้งชื่อเช่น "ส่งบิล"
2. เพิ่มคำถาม **ชื่อคำถามต้องตรงตามนี้ทุกตัวอักษร**

   | ชื่อคำถาม | ประเภท | หมายเหตุ |
   |---|---|---|
   | `ชื่อผู้แทน` | Dropdown (ใส่ชื่อผู้แทนทุกคน) หรือ Short answer | ตั้งเป็น Required |
   | `รูปบิล` | File upload | อนุญาตเฉพาะ Image และ PDF, จำนวนไฟล์สูงสุด 10, ขนาดสูงสุด 10 MB, ตั้งเป็น Required |
   | `หมายเหตุ` | Short answer | ไม่บังคับ (ไม่ใส่ก็ได้) |

   ถ้าอยากใช้ชื่อคำถามอื่น ให้แก้ `Q_REP`, `Q_PHOTO`, `Q_NOTE` ในส่วน `CONFIG` ของโค้ดให้ตรงกัน

3. คำถามแบบ File upload บังคับให้ผู้ตอบล็อกอิน Google ผู้แทนทุกคนจึงต้องมีบัญชี Google (Gmail ส่วนตัวก็ได้)
4. แท็บ **Responses** > กด **Link to Sheets** > **Create a new spreadsheet**

## ขั้นที่ 3 — ใส่สคริปต์ (10 นาที)

1. เปิด Google Sheet ที่เพิ่งสร้าง
2. เมนู **Extensions (ส่วนขยาย) > Apps Script**
3. ลบโค้ดเดิมใน `Code.gs` ทั้งหมด แล้ววางโค้ดจากไฟล์ [`Code.gs`](Code.gs) ทั้งไฟล์
4. กดไอคอนบันทึก (💾)
5. เลือกฟังก์ชัน `setup` ในแถบด้านบน แล้วกด **Run**
6. Google จะขอสิทธิ์: กด **Review permissions** > เลือกบัญชี > ถ้าขึ้น "Google hasn't verified this app" ให้กด **Advanced** > **Go to ... (unsafe)** > **Allow**
   (เป็นสคริปต์ของเราเอง จึงยังไม่ผ่านการรับรองจาก Google ถือเป็นเรื่องปกติ)
7. กลับไปที่หน้า Google Sheet จะมีกล่องให้วาง API key ให้วาง key จากขั้นที่ 1 แล้วกด OK
8. รอข้อความ "Bill reader is set up" ซึ่งจะบอกว่า key ใช้ได้หรือไม่ และแสดงลิงก์โฟลเดอร์บิล

เสร็จแล้ว ตั้งแต่นี้ทุกครั้งที่มีคนส่งฟอร์ม ระบบจะทำงานเองภายในประมาณ 10–30 วินาที

## ขั้นที่ 4 — ทดสอบ

1. เปิดลิงก์ฟอร์มจากมือถือ ส่งรูปบิล 1 ใบ
2. รอประมาณ 30 วินาที แล้วดูชีต **Bills** ควรมีแถวใหม่ และไฟล์ในโฟลเดอร์ "Bills (auto-renamed)" ถูกเปลี่ยนชื่อแล้ว
3. ถ้าไม่มีอะไรเกิดขึ้น: ใน Apps Script ไปที่เมนูซ้าย **Executions** เพื่อดูข้อความ error

## ขั้นที่ 5 — ส่งลิงก์ให้ผู้แทน

ในฟอร์มกด **Send** > ไอคอนลิงก์ > คัดลอก แล้วส่งให้ผู้แทน ผู้แทนสามารถเพิ่มลิงก์ไว้ที่หน้าจอหลักของมือถือได้ (Chrome > ⋮ > เพิ่มลงในหน้าจอหลัก)

## การใช้งานประจำวัน

ในชีตจะมีเมนู **Bill reader** (ถ้าไม่เห็นให้รีเฟรชหน้า)

| เมนู | ใช้เมื่อ |
|---|---|
| Re-read selected bills | เลือกแถวในชีต Bills แล้วสั่งอ่านใหม่ เช่น หลังเปลี่ยนรุ่น Gemini หรือแก้ prompt |
| Process all ERROR rows again | อ่านทุกแถวที่เป็น ERROR ใหม่ เช่น หลัง Gemini ล่มหรือโควตาเต็มชั่วคราว |
| Change Gemini API key | เปลี่ยน key |
| Run setup | ติดตั้งซ้ำ (ทำซ้ำได้อย่างปลอดภัย ไม่สร้าง trigger ซ้ำ) |

**แถวที่เป็น CHECK:** เปิดรูปจากคอลัมน์ File แล้วแก้ข้อมูลในชีตด้วยมือ จากนั้นเปลี่ยน Status เป็น OK

**ถ้ารูปไม่ชัด:** ให้ผู้แทนส่งรูปใหม่ แถวใหม่จะถูกระบุว่า "Duplicate bill number" หากอ่านเลขที่บิลได้ซ้ำกับแถวเดิม ให้ลบแถวที่ผิดออก

## ปรับแต่ง (ส่วน `CONFIG` บนสุดของโค้ด)

| ค่า | ความหมาย |
|---|---|
| `FOLDER_ID` | ใช้โฟลเดอร์ Drive ที่มีอยู่แล้ว (คัดลอก ID จาก URL ของโฟลเดอร์) ถ้าเว้นว่าง ระบบจะสร้างโฟลเดอร์ให้เอง |
| `MONTH_SUBFOLDERS` | `false` = ไม่แยกโฟลเดอร์ตามเดือน |
| `GEMINI_MODEL` | รุ่น Gemini ถ้า Google เลิกให้บริการรุ่นนี้ ให้เปลี่ยนเป็นรุ่น Flash ล่าสุดที่ AI Studio แสดงอยู่ |
| `TOTAL_TOLERANCE` | ยอมให้ยอดรายการกับยอดรวมต่างกันได้กี่บาท (ระบบรู้จัก VAT 7% แล้ว) |

## คำถามที่พบบ่อย

- **ฟรีจริงไหม?** Apps Script, Forms, Sheets, Drive ฟรี ส่วน Gemini แบบฟรีรองรับหลายร้อยบิลต่อวัน ถ้าใช้เกิน ระบบจะรอแล้วลองใหม่ หากยังไม่ได้จะแสดง ERROR ให้ใช้เมนู "Process all ERROR rows again" ภายหลัง
- **อ่านลายมือได้ไหม?** ได้พอสมควร แต่ช่องที่ไม่แน่ใจจะถูกระบุเป็น "Unclear: ..." ให้ตรวจ
- **ปี พ.ศ.?** ระบบแปลงเป็น ค.ศ. ให้ในคอลัมน์ Bill date (รูปแบบ YYYY-MM-DD)
- **มีคนแก้สคริปต์ได้ไหม?** เฉพาะคนที่มีสิทธิ์แก้ไข Google Sheet นี้ อย่าแชร์สิทธิ์แก้ไขให้ผู้แทน ผู้แทนใช้แค่ลิงก์ฟอร์ม
