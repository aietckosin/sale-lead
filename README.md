# Sale Lead

หน้าทางเข้าแอปบันทึกลูกค้า (Sale Lead) พร้อมไอคอนสำหรับเพิ่มลงหน้าจอหลักของโทรศัพท์

เปิด https://aietckosin.github.io/sale-lead/ ใน Chrome แล้วเลือก "เพิ่มลงในหน้าจอหลัก"

ไม่มีข้อมูลลูกค้าในที่เก็บนี้ ข้อมูลทั้งหมดอยู่ใน Google Drive

## ระบบอ่านบิลอัตโนมัติ

ผู้แทนส่งรูปบิลผ่าน Google Form แล้วระบบจะเปลี่ยนชื่อไฟล์เป็นเลขที่บิล และบันทึกข้อมูลบิลลง Google Sheet (ดาวน์โหลดเป็น Excel ได้) ให้อัตโนมัติ
